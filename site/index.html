Sage is a private personal assistant that runs on its owner’s Mac. It helps organize email, calendars, files, research, reminders, and daily work while keeping consequential actions behind explicit approval.

Local AI processing No advertising User-controlled access

How Sage works

Useful access without silent authority.

01

Read with purpose

Sage reads connected Google data only to provide requested assistance, monitoring, search, and reminders.

02

Ask before impact

Sending email, deleting data, and other consequential actions require a separate user confirmation.

03

Keep control local

Operational records and AI processing stay on the owner’s computer. Access can be revoked at any time.

Google integrations

Specific access for specific jobs.

GmailSearch, summarize, monitor, prepare drafts, and send only after approval.
Google CalendarRead events, create reminders, and manage events when requested.
Google DriveFind files and perform explicit file operations under user control.
